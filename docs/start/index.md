# Start here

This section is for anyone meeting DEVAI 3 for the first time: a pilot (the application architect or
engineer who states intent and approves specs), a product engineer, or a coding agent's operator.

| Page | What you get |
|---|---|
| [What is DEVAI?](what-is-devai.md) | The product in one page: rail, harness, two file formats, one acceptance rule |
| [Quickstart](quickstart.md) | From `devai init` to your first packet check on the shipped `demo` fixture |
| [Reading order](reading-order.md) | Which pages to read next, by audience |
| [Concepts at a glance](concepts-at-a-glance.md) | One paragraph each on spec, packet, campaign, node, status, edit loop, hooks, review, sensor, template and generator |

DEVAI 3.0.0 is unreleased. The pages describe the behaviour the framework specifies; the CLI, the
decorators and the template arrive with the release.
